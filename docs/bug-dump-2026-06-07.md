## Theme A — Nikud not respecting the toggle

> Triage insight: there are **two** nikud systems. (1) `stripNikud`/`showNikud` governs Hebrew **word/sentence DATA**. (2) `nk()` governs hardcoded Hebrew **chrome** literals. Bugs below split across both — tag which when fixing.
>
> **Resolution (2026-06-07).** Two root causes, both fixed:
> 1. **Wiring** — non-vocab Hebrew (grammar/article/story sentences, glosses, translations) was rendered raw or via a *strip-only* path (`showNikud ? s : stripNikud(s)`), which never adds points when the toggle is ON because that Hebrew isn't pre-enriched at boot like vocab `word.hebrew`. Switched those to `applyNikud()`/`nk()` (the nikud-map lookup that adds points ON and strips OFF).
> 2. **Map coverage** — `scripts/build-nikud-map.py` only scanned `.js`/`.html`, so React `.tsx` chrome (`נלמד`, `הביתה`, `וכשמוכנים`…) was never collected, and newer `.js` data banks were stale. Extended the glob to `.ts`/`.tsx` and re-ran → `data/nikud-map.json` 2551→3360 entries; all five data banks now 100% covered.
